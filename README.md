# 🚀 Flutter Employee Management

A modern, responsive **Flutter Employee Management Dashboard** designed for company operations. Built with clean architecture, reusable widgets, and a polished interface that works seamlessly across **Web, Tablet, and Mobile**.

---

## ✨ Features

* Responsive layout for **Desktop, Tablet & Mobile**
* Modern company management dashboard
* Employee management module
* Attendance tracking with calendar
* Project summary and performance analytics
* Company announcements & information
* Profile & settings management
* Smooth adaptive navigation
* Reusable widget-based architecture
* Interactive charts and analytics

---

## 🛠 Tech Stack

* **Flutter**
* **Dart**
* **Google Fonts**
* **fl_chart**
* **table_calendar**
* **intl**

## 🚀 Getting Started

### Prerequisites

* Flutter SDK >= 3.27.4
* Dart SDK >= 3.0.0

### Installation

```bash
git clone https://github.com/shikhar11x/Flutter-Employee-Management.git

cd Flutter-Employee-Management

flutter pub get

flutter run
```

### Run on Web

```bash
flutter run -d chrome
```
